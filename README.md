# ایجنت بررسی محصولات ترب

نمونهٔ اولیهٔ محلی برای پیشنهاد تصمیم به کارشناس. Python 3.11+ کافی است.
ورودی یک شیء JSON از ورودی استاندارد است و خروجی شامل `decision` و `reason` است.
خروجی جداسازی فیلد `groups` هم دارد.

```bash
python3 agent.py <<'JSON'
{"kind":"merge","category":"cable","left":{"model":"A10","length":"۱ متر"},"right":{"model":"A10","length":"۲ متر"}}
JSON
python3 -m unittest discover -s tests
```

برای ادغام، `left` و `right` شواهد استخراج‌شده توسط کارشناس هستند.
مقادیر ساختار، وضعیت، تعداد و طول را با قالب یکسان وارد کنید. عنوان خام برای
تشخیص واژه‌های وضعیت استفاده می‌شود. مدل و برند باید هویت تجاری را نشان دهند.
پرچم‌های `images_checked`، `cluster_checked` و `single_model_confirmed`
را فقط پس از بررسی واقعی فعال کنید. در صورت تعارض شواهد
`conflicting_evidence` را فعال کنید.

برای جداسازی، `kind` را `split` بگذارید. پس از بررسی کامل کلاستر،
`cluster_checked` و `verified_split_groups` را بدهید. هر گروه آرایه‌ای
از شناسه‌های اعضایی است که باید با هم یک بیس تشکیل دهند.
درخواست حذف به کارشناس ارجاع می‌شود.

دامنهٔ نسخهٔ فعلی هستهٔ پیشنهاددهی است. اتصال به پنل و افزونهٔ Chrome،
استخراج خودکار شواهد، OCR، صف و ارزیابی با داده‌های واقعی مراحل بعدی‌اند.
قواعد مرجع در [سند قواعد](rules/torob-merge-split-rules.md) آمده‌اند.
